# Expansion plates (not in the v1 game)

These 1600×900 WebP paintings are for later branches. Nothing in `data/world.json` points at them, and the service worker only caches paths listed there, so they do not change the v1 game.

Style follows the locked warm storybook gouache and a painted scene used as the reference. They are full-bleed plates, not cutouts.
