# Bronco Living Room — for parents

A quiet free-play game for ages ~3–6: drive a mini Bronco around a playroom, shove soft toys, paint your truck. No score, no levels, no “you lost.”

## Setup

1. Open the shared link on a **tablet** in Safari (iPhone/iPad) or Chrome (Android), on Wi‑Fi.
2. Don’t open a downloaded file from Files/Downloads — tilt usually won’t work that way.
3. First time needs Wi‑Fi so the game can finish loading.
4. First tap **🚗 Drive!** — if iOS asks for Motion, tap Allow once (you can do it). **Stick** and **GO** still work if tilt doesn’t.

## What kids do

- Drive around and bump soft toys — sparkles mean a good shove.
- Stuck in a corner? Tap **🔄 Spin!** — it’s a little celebration, not a fail.
- Optional: **🎨 Paint** the Bronco (body, roof, wheels, size) before driving.
- Come back to paint anytime from the start screen.

## What not to worry about

- Short sits (a few minutes) are normal.
- **Home** needs a long-press or double-tap so little thumbs don’t eject by accident.
- Bumping furniture and toys *is* the play — nothing breaks.
- The game is **silent on purpose**.
- If the room won’t show, try another browser or device — that’s the device, not your child.
